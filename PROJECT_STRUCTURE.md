## Current Launch Flow

Current working command:

```bash
ros2 launch articubot_one launch_sim.launch.py world:=$HOME/tekno_robot_simulation/src/articubot_one/worlds/teknofest_arena.world use_ros2_control:=true
```

Primary launch entry:

- `launch/launch_sim.launch.py`

Directly included by `launch_sim.launch.py`:

- `launch/rsp.launch.py`
- `launch/joystick.launch.py`
- `slam_toolbox/launch/online_async_launch.py` when `start_slam:=true`

## Structure Upgrade Direction

Keep the current package and launch flow. Add forklift functionality inside `articubot_one` rather than creating a replacement package:

- Add forklift xacro pieces to `description/`.
- Add fork controller config to `config/my_controllers.yaml`.
- Add new ROS 2 Python nodes under `articubot_one/articubot_one/`.
- Keep executable install rules in `CMakeLists.txt` consistent with existing package style.
- Preserve existing map, world, QR textures, Nav2 params, camera/lidar topics, and frame names.
